# Instagram · Elite Recovery

Images et légendes des posts Instagram de @eliterecovery.ch, publiés automatiquement par le robot (`publier.py`, lancé par GitHub Actions toutes les 30 minutes).

- `calendrier.json` : les posts, leur date et leur heure
- `images/` : les images, dans l'ordre du carrousel
- `publies.json` : ce qui a déjà été publié

Pour mettre le robot en pause : Settings › Secrets and variables › Actions › Variables › `IG_PAUSE` = `oui`.
